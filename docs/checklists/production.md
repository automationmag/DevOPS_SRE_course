# Чеклист продакшена

Открывать перед фразой «можно пускать людей». Не снимайте галочки авансом.

## Модули 0–5

- [ ] На сервер вхожу по SSH-ключу, не по паролю
- [ ] Пользователь не-root, `PermitRootLogin no`
- [ ] Система обновлена, ufw включён, лишние порты закрыты
- [ ] Swap есть, `free -h` не показывает нули сразу после загрузки
- [ ] Приложение в Docker, после ребута поднимается само
- [ ] В интернет торчит только 80/443 (или только 80, пока нет домена — и вы понимаете риск)
- [ ] Секреты в `.env`, файла нет в git
- [ ] Домен указывает на IP, в браузере замочек HTTPS
- [ ] Прямой порт приложения (например 8000) снаружи закрыт
- [ ] Строка сервера записана в [инвентарь](../inventory-template.md)

## Модули 6–12

- [ ] Бэкап есть **и** проверено восстановление
- [ ] Staging описан (хотя бы Docker на ноутбуке)
- [ ] `.env` разный у сред, ротация понятна
- [ ] Код в git; `mkdocs build --strict` проходит
- [ ] Знаете, как откатиться к коммиту
- [ ] Логи смотрите осознанно, пароли в них не пишутся
- [ ] Есть сигнал «сайт лежит» в Telegram
- [ ] Диск хотя бы в воскресном просмотре или в скрипте
- [ ] Записаны SLI/SLO/бюджет
- [ ] Один учебный инцидент разобран без самобичевания

## Модули 13–17

- [ ] Понятно, что расти первым: RAM, диск, очередь или лимит API — не «сразу k8s»
- [ ] Админки не торчат в интернет; лишние ключи умеете отозвать
- [ ] Если есть оплата — вебхуки, идемпотентность, сверка; иначе пункт неприменим
- [ ] Инвентарь живой, календарь оплат, биллинг-алерт хостера
- [ ] Диплом сервиса и (по возможности) учебника на Pages пройден честно

## Понимание 18–19 (не установка на 1 ГБ)

- [ ] Можете объяснить Pod / Service / Ingress аналогиями Compose
- [ ] Знаете, почему кластер не на 1 ГБ
- [ ] Таблица «VPS → AWS → Yandex» из восьми строк с закрытыми глазами
- [ ] В облаке нет забытых учебных ресурсов

Полный проход диплома сервиса — модуль 17. Kubernetes и AWS — диплом понимания.
