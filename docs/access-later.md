# Как потом дать доступ другим

Сейчас курс для вас. Ниже — развилка **на потом**, без платёжки и без LMS.

## Вариант 1. Ссылка на GitHub Pages

Сайт статический: HTML, CSS, JS. Кто знает адрес — тот читает.

Подходит, если не секрет, что вы учитесь, и в текстах нет ваших IP и ключей (их и не должно быть).

## Вариант 2. Приватный репозиторий

Код и тексты видят только те, кого вы добавили в GitHub. Pages для приватных репозиториев на бесплатном тарифе может быть недоступен — тогда читают локально через `mkdocs serve` или вы кладёте статику на свой сервер.

## Вариант 3. Свой сервер + пароль

Собранную папку `site/` кладёте за Caddy. Включаете basic auth: один логин и пароль на всех или разные. Это не «платформа курсов», это замок на учебнике.

Когда дойдёте до модуля 5, вы уже будете понимать, куда в Caddy поставить такой замок. Готовый фрагмент появится в волне про доступы.

## Чего не делаем сейчас

- Оплату за уроки (ЮKassa — тема модуля 15 про **ваш продукт**, не про этот учебник).
- Личные кабинеты учеников, прогресс в облаке, антипиратство.

Архитектура уже позволяет открыть доступ: это просто файлы. Сложность «подписки на курс» — отдельный продукт, его можно навесить позже.
