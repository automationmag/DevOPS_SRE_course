# Модуль 10. Наблюдаемость

Логи отвечают «что случилось в этот раз». Метрики — «насколько плохо в целом». Трейсы — «куда ушёл один запрос». Вместе это называют наблюдаемостью. На 1 ГБ вы внедряете тонкий слой; толстый стек изучаете как грамотность.

2. [Лёгкий стек на 1 ГБ](02-legkiy-stek.md)

**Не ставить на учебный VPS вместе:** Prometheus + Grafana + Loki + «Пульс». Нужно от 2–4 ГБ или облачная Grafana.
