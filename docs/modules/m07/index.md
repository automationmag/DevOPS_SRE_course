# Модуль 7. Секреты и среды

Один и тот же код должен запускаться у вас на ноутбуке, на репетиции и в проде. Различаются **настройки и ключи**, не ветки с хаотичными правками «на сервере навсегда».

Уроки:

1. [Три среды и .env](01-tri-sredy.md)
2. [Staging как репетиция](02-staging.md)
3. [Ротация: ключ засветился](03-rotaciya.md)
4. [Лаборатория. Два .env](../../labs/lab-07-dve-sredy.md)

**Нагрузка:** влезает в 1 ГБ. Второй полноценный VPS для staging не обязателен: репетиция может быть другим именем и другим `.env` на той же машине *очень осторожно*, либо только на ПК. В уроках честно разведём варианты.
