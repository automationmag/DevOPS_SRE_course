# Глоссарий

Слова, которые встречаются в курсе. Если термин ещё не появлялся в уроке — можно не зубрить заранее.

| Термин | Простыми словами |
|---|---|
| **VPS** | Арендованный компьютер в дата-центре, который работает круглосуточно |
| **Прод / production** | Живая версия, которой пользуются реальные люди |
| **Staging** | Черновик прода: тот же запуск, но адрес знаете только вы |
| **SSH** | Зашифрованный способ открыть терминал сервера по сети |
| **SSH-ключ** | Пара файлов «замок и ключ» вместо пароля |
| **root** | Суперпользователь Linux. Может всё, включая сломать всё |
| **sudo** | «Сделай эту одну команду как root» |
| **IP-адрес** | Цифровой адрес машины в сети |
| **Домен** | Имя вроде `example.ru` вместо цифр |
| **DNS** | Записная книжка интернета: какое имя на какой IP |
| **Порт** | Номер двери на сервере. Сайт обычно 80 и 443 |
| **Файрвол** | Список: кому какие двери открыты |
| **Секрет** | Пароль, токен, ключ API. Нельзя в git и в чат |
| **`.env`** | Файл с секретами и настройками рядом с проектом |
| **Контейнер** | Изолированная коробка, в которой запущено приложение |
| **Образ Docker** | Рецепт + заготовка для таких коробок |
| **Том (volume)** | Папка снаружи контейнера, чтобы данные не умерли вместе с коробкой |
| **Compose** | Файл, где описано: какие коробки запустить и как они связаны |
| **Reverse proxy / вахтёр** | Программа на входе (Caddy, Nginx): принимает HTTPS и ведёт в нужный контейнер |
| **HTTPS** | Сайт с замочком: дорога между браузером и сервером зашифрована |
| **Сертификат** | Документ «да, этот домен — действительно этот сервер» |
| **Let's Encrypt** | Бесплатный автоматический выдаватель сертификатов |
| **Лог** | Дневник программы |
| **Метрика** | Число, которое снимают регулярно: память, ошибки, запросы |
| **Алерт** | Сообщение «пора действовать», а не просто уведомление |
| **Бэкап** | Копия данных, из которой можно восстановиться |
| **Деплой** | Выкладка новой версии на сервер |
| **CI/CD** | Робот: проверил код и выложил |
| **Откат (rollback)** | Вернуть предыдущую рабочую версию |
| **Инцидент** | Сбой, который затронул (или мог затронуть) пользователей |
| **Runbook** | Короткая инструкция «если сигнал X — делай 1-2-3» |
| **SLO** | Договор с собой: насколько сервис должен быть доступен |
| **Kubernetes** | Система, которая держит много коробок на многих серверах и чинит их сама. На 1 ГБ не живёт |
| **AWS** | Большое зарубежное облако с кучей готовых сервисов. Это не ваш текущий VPS |
| **3-2-1** | Три копии, два разных носителя, одна копия не на этом сервере |
| **RPO / RTO** | Сколько данных можно потерять по времени / за сколько поднимаем обратно |
| **SLI** | Как измеряем здоровье, например доля успешных /health |
| **Бюджет ошибок** | Сколько ещё можно «не попасть в SLO» в этом периоде |
| **Трейс** | Таймлайн одного запроса по кускам системы |
| **Prometheus** | Складывает числа-метрики, сам ходит на /metrics |
| **Grafana** | Рисует графики из Prometheus и других источников |
| **Loki** | Склад логов; на VPS 1 ГБ не ставим |
| **Alertmanager** | Почтальон алертов Prometheus |
| **Uptime-проверка** | Робот периодически открывает ваш URL |
| **Postmortem** | Короткий разбор инцидента без поиска виноватого |
| **Пайплайн / workflow** | Цепочка шагов робота CI/CD |
| **Вертикаль / горизонталь** | Сильнее одна машина / несколько за балансировщиком |
| **Очередь / воркер** | Задача делается потом отдельным процессом, не в клике страницы |
| **Мультитенантность** | Клиент А не видит данные клиента Б |
| **Вебхук** | Чужой сервис сам сообщает вам о событии на ваш HTTPS |
| **Идемпотентность** | Повтор того же события не меняет мир второй раз |
| **Pod** | Обёртка над контейнером в Kubernetes |
| **Deployment** | Как выкатывать приложение и сколько копий держать |
| **Service** | Стабильное имя внутри кластера, аналогично имени в Docker-сети |
| **Ingress** | Вахтёр кластера: домен и путь → Service |
| **PVC** | Заявка на диск, аналог тома Compose |
| **Control plane** | Мозг кластера: API, расписание, записная книжка |
| **IAM** | Кто что может в облаке (не путать с файрволом портов) |
| **VPC** | Ваша частная сеть в облаке |
| **Security group** | Файрвол вокруг сетевого интерфейса облачной машины |
| **EC2 / S3 / RDS** | VPS / шкаф файлов / управляемая база в AWS |
| **IaC / Terraform** | Инфраструктура описана текстом в git |
