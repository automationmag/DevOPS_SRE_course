# Runbook: сертификат истекает

**Сигнал:** браузер пишет, что соединение небезопасно. Или вы вспомнили, что HTTPS настраивали «когда-то».

На учебном стеке курса сертификат выдаёт **Let's Encrypt через Caddy**. Обычно Caddy **сам продлевает** его, если:

- сервер включён;
- порты 80 и 443 снаружи открыты;
- домен по-прежнему указывает на этот IP.

## Проверить

```bash
cd /opt/pulse
docker compose logs caddy --tail=80
```

Ищите строки про `certificate` / `renewal`. В браузере: замочек → срок действия сертификата (должно быть не дни, а месяцы, если недавно выпускали).

## Если не продлился

1. DNS: A-запись домена всё ещё на ваш IP? Проверка с компьютера:

```bash
nslookup ваш-домен.ru
```

2. Файрвол: `sudo ufw status` — 80 и 443 разрешены.

3. Caddy запущен: `docker compose ps`.

4. Лимит Let's Encrypt: слишком много попыток за неделю — подождать. Не тыкайте выпуск в цикле.

Пока модуля 5 нет в вашем прохождении, этой карточки вам нечем нарушить. Вернитесь сюда после лаборатории про HTTPS.

**Влезает в 1 ГБ:** да.
